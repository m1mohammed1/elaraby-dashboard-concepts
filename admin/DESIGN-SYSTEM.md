# نظام تصميم لوحة إدارة العربي

هذا عقد، لا توثيق. كل بند فيه ناتج عن خطأ حقيقي ظهر أثناء بناء «النظرة العامة»
واستغرق إصلاحه عدة جولات. المخالفة تعني إعادة اكتشاف نفس العيب في صفحة أخرى.

الشاشة المرجعية المعتمدة: `prototype/gallery/overview.html`. عند أي التباس، افتحها
واتبع ما فيها حرفيًا.

---

## 0. المحرَّمات — اقرأ هذه أولًا

هذه ليست تفضيلات. كل واحدة منها كانت عيبًا مرئيًا شكا منه صاحب المنتج.

| ممنوع | السبب |
|---|---|
| `backdrop-filter` بأي شكل | يسحب عيّنة من الخلفية ولا يعيد حسابها عند التمرير، فيترك شبحًا أفتح من اللوحة. المشهد مضبَّب أصلًا بـ `blur(110px)` فالمكسب صفر. |
| `position: fixed` لأي عنصر | المتصفّح يركّبها في طبقة منفصلة لا يعاد رسمها بشكل موثوق مع التمرير، فيبدو أسفل الصفحة أفتح حتى أول إعادة رسم. |
| `transform` على لوحة زجاجية أو على أب لها | نفس عائلة العيب: يجمّع العنصر في طبقة مؤقّتة ويترك أثرًا على الحواف. |
| أي `animation` أو `transition` على اللوحات الزجاجية | نفس السبب. الحركة تكون على المحتوى غير الزجاجي فقط. |
| `display:flex` لصفوف الجداول | الصفوف تحمل حقولًا اختيارية (اسم الجهة مثلًا)، فتتزحزح الأعمدة بين صف وآخر. |
| مقاييس مزدوجة على محور واحد، أو تكبير سلسلة لتبدو مرئية | تضليل. استخدم رسمين بمحور سينيّ مشترك وصرّح بذلك. |
| اختراع رقم غير موجود في قاعدة البيانات | راجع §7. الأرقام المخترعة تُكتشف وتُفقد الثقة. |
| `left`/`right`/`margin-left`… حيث تصلح الخصائص المنطقية | يكسر الاتجاه في RTL. |

## 1. المشهد

```css
html,body{ min-block-size:100% }          /* لا height — الجسم يكبر مع المحتوى */
body{ position:relative; background:#06100c }
.scene{ position:absolute; inset:0; z-index:0; pointer-events:none; overflow:hidden }
.grain{ position:absolute; inset:0; z-index:60; pointer-events:none; opacity:.035 }
```

خمسة مصادر ضوء، كل واحد `border-radius:50%` و `filter:blur(110px)` وشفافية بين
`.10` و `.19`، بألوان: `#0f4d38` `#10613f` `#0b3a30` `#145a45` `#08302a`.
فوقها تظليل: `radial-gradient(ellipse 125% 92% at 50% 44%, transparent 28%, rgba(0,0,0,.66) 100%)`.
وحبيبات من `feTurbulence` بشفافية `.035`.

انسخ كتلة المشهد من الشاشة المرجعية كما هي. الإضاءة مضبوطة بعد طلبين متتاليين
بتهدئتها، فلا ترفعها.

## 2. المادة — اللوحة الزجاجية

```css
.pane{
  position:relative;
  border-radius:16px;
  border:1px solid rgba(255,255,255,.085);
  box-shadow:0 1px 0 0 rgba(255,255,255,.10) inset,   /* اللمعة العلوية */
             0 20px 50px -22px rgba(0,0,0,.55);
}
```

الخلفية وحدها هي ما يتغيّر بحسب العمق:

| الطبقة | الخلفية | الاستخدام |
|---|---|---|
| خلفية `.far` | `rgba(255,255,255,.050)` | سياق: رسوم كبيرة، خلفيات |
| متوسط `.mid` | `rgba(255,255,255,.058)` | الأرقام والجداول الرئيسية |
| أمامي `.near` | `rgba(255,255,255,.080)` | ما يستحق الانتباه؛ حدّ `.13` وظل أعمق |

**اللوحة لا تحمل لونًا أبدًا.** كل اللون في المشهد خلفها. الإحساس الزجاجي يأتي من
البياض الشفّاف + اللمعة العلوية + الحدّ الرفيع + الظل. لا شيء غير ذلك.

## 3. التوكنز

```css
:root{
  --ink:#f1f6f3; --ink-2:#bac6c0; --ink-3:#87938c; --ink-4:#7b8780;
  --line:rgba(255,255,255,.09); --line-2:rgba(255,255,255,.05);
  --accent:#6ec49b;
  --wanted:#ff6b6b;      /* مطلوب — قانون منتج، لا يُعاد تعيينه */
  --clean:#3ddc97;       /* غير مطلوبة — قانون منتج */
  --unread:#e8b055;      /* تحذير/انتظار */
  --ease:cubic-bezier(.22,.61,.36,1);
}
```

اللون الوحيد المسموح خارج المشهد وحالات الحالة هو `--accent` وبقدر ضئيل.
توهّج واحد فقط في الشاشة كلها، ونبضة واحدة فقط.

## 4. الخط

`font-family:'IBM Plex Sans Arabic', system-ui, sans-serif` من Google Fonts.

- الأرقام: `font-variant-numeric:tabular-nums; font-feature-settings:"tnum" 1`
- **أرقام غربية في كل مكان** (`24` لا `٢٤`)
- `line-height` للنص العربي ≥ 1.7
- `letter-spacing` يبقى `normal` دائمًا — يكسر وصل الحروف العربية
- أي رقم داخل SVG: `direction:ltr; unicode-bidi:isolate` وإلا انقسم «00» إلى «0 0»

---

## 5. RTL — أخطاء وقعت فعلًا

- خصائص منطقية دائمًا: `margin-inline-start`, `padding-inline-end`,
  `border-start-end-radius`, `inset-inline-start`.
- **`viewBox` في SVG اتجاهه LTR دائمًا.** `dir="rtl"` لا يعكس داخله. لعرض محور
  زمني بالعربي اعكس البيانات: `x = W - PAD.r - (i+0.5)*SLOT`.
- حساب المؤشّر داخل SVG: `e.clientX - rect.left` — **لا** `rect.right - e.clientX`.
- اللوحات والنصوص المختلطة (عربي + أرقام): `direction:rtl; unicode-bidi:isolate`.

## 6. التخطيط والتكيّف

```css
.stage{ inline-size:100%; max-inline-size:1560px; margin-inline:auto; padding:24px 26px 30px }
```

الصفحة **تتوقّف عن التمدّد** عند 1560px وتتمركز. نقاط التكيّف الموحّدة:

| العرض | السلوك |
|---|---|
| ≥ 1280 | عمودان: محتوى + عمود جانبي 364px |
| 1080–1279 | عمودان، الجانبي 300px |
| < 1080 | عمود واحد |
| < 760 | صفوف الجداول تصير سطرين |
| < 620 | حشو أصغر، حجم الأرقام أصغر |

`repeat(auto-fit, minmax(Npx,1fr))` يفيض تحت `N`. استخدم أعدادًا صريحة عند كل
نقطة، أو `minmax(min(Npx,100%),1fr)`.

## 7. الصدق في البيانات — إلزامي

هذا نظام حقيقي لفحص لوحات المركبات. ما لا تعرفه قاعدة البيانات لا يُعرض.

**غير موجود إطلاقًا — لا تعرضه بأي صيغة:**
بوابات أو مواقع أو فروع · لوحات غير مقروءة · زمن معالجة · دقة تعرّف أو ثقة ·
قراءة آلية للوحات · ساعات اتصال تاريخية · محاولات دخول فاشلة.

**موجود ومتاح الآن:** عدد الفحوصات لليوم · المطلوبون ونسبة الإصابة ·
المشغّلون الذين فحصوا · المتصلون الآن والجلسات الصوتية (لحظي فقط، TTL دقيقتان) ·
آخر 20 فحصًا · حجم قائمة المطلوبين وآخر استيراد ومن نفّذه · تقرير مشغّل على مدى حر ·
عدد المشغّلين والاشتراكات السارية.

`result` في السجل قيمتان فقط: `safe` و `wanted`. تُعرضان **«غير مطلوبة»** و**«مطلوب»**.
لا تستخدم كلمة «سليم».

كل صفحة تحمل مفتاحًا في الشريط العلوي باسم **«مصادر البيانات»**؛ عند تشغيله يظهر
أسفل كل لوحة سطر يذكر مسار الـ API أو الحقل الذي يغذّيها، ويصرّح بما يحتاج بناءً
جديدًا. هذا يجعل الموك مواصفةَ تنفيذ في الوقت نفسه.

كل صفحة تنتهي بسطر: `بيانات توضيحية — ليست بيانات حقيقية · نظام العربي لفحص اللوحات`.

## 8. المكوّنات

انسخ هذه من الشاشة المرجعية بدل إعادة كتابتها.

**الشريط العلوي** — `.bar` بخلفية `rgba(255,255,255,.05)`، بداخله `.barIn` بعرض
أقصى 1560px متمركز، يحوي: الهوية · التنقّل · أدوات الصفحة · مفتاح مصادر البيانات ·
هوية المستخدم (**أحمد عماد** — مدير النظام).

**التنقّل** — روابط الصفحات السبع. الرابط النشط بخلفية `rgba(255,255,255,.10)`.

**مقسّم مجزّأ `.seg`** — أزرار داخل إطار، `aria-pressed` على المختار.

**صف جدول** — `display:grid` بأعمدة صريحة، والأعمدة الاختيارية **محجوزة دائمًا**
حتى حين تكون فارغة:
```css
.row{ display:grid; grid-template-columns:38px 108px 16px minmax(0,1fr) 160px 66px 78px;
      align-items:center; gap:11px }
```
تحت 760px يصير الصف سطرين بمواضع `grid-area` صريحة.

**شارة الحكم** — حبة بحدّ `currentColor`: `.vw{color:var(--wanted)}` /
`.vs{color:var(--clean)}`.

**زر الموقع** — منقول حرفيًا من `admin-client/src/features/operators/WorkHistory.tsx`:
أيقونة دبوس + كلمة «الموقع»، رابط `https://www.google.com/maps/search/?api=1&query=LAT,LNG`
بـ `target="_blank" rel="noreferrer"` عند وجود الإحداثيات، وزر `disabled` مع
`aria-label="موقع اللوحة غير متاح"` عند غيابها. الحقل اختياري فعلًا.

**قائمة منسدلة** — خلفية **معتمة** `#101b16`، و`z-index` عالٍ، والقسم الحاوي لها
مرفوع بـ `position:relative;z-index:60` وإلا حُبس ترتيبها داخل سياق تكديس الأب.

**حالة فارغة** — لكل تصفية قد لا تُرجع شيئًا: `لا توجد سجلات مطابقة` مع تلميح.

**التركيز** — `:focus-visible{ outline:2px solid var(--accent); outline-offset:2px }`
على كل عنصر تفاعلي. أي عنصر قابل للنقر يكون `<button>` أو `<a>` حقيقيًا.

## 9. الحركة

ثلاثة أنواع فقط، ولا شيء منها على الزجاج:

1. **الأرقام** — عدّ تصاعدي 900ms. القيمة الحقيقية **مكتوبة في الـ markup**
   والحركة فوقها، لأن `requestAnimationFrame` يُخنق في التبويب المخفي فيبقى
   العدّاد على صفر.
2. **الرسوم** — الأعمدة تنمو والخطوط تُرسم، مرة واحدة عند التحميل وعند تغيّر البيانات.
3. **التفاعل** — مرور ونقر وتركيز، 120–200ms.

نبضة واحدة مسموحة في الشاشة كلها (مؤشّر «حيّ»). لا حركة خلفية مستمرة.

```css
@media (prefers-reduced-motion: reduce){ *,*::before,*::after{
  animation-duration:.01ms !important; animation-iteration-count:1 !important;
  transition-duration:.01ms !important } }
```

الحالة الأساسية لأي عنصر متحرّك تكون **ظاهرة**: لو لم تُنفَّذ الحركة تبقى الصفحة
مقروءة بدل أن تكون فارغة.

## 10. الرسوم

- الرسم يقرأ **عرضه وارتفاعه من صندوقه الفعلي بالبكسل** ويضبط
  `viewBox="0 0 W H"` منهما، مع `preserveAspectRatio="none"` وارتفاع مثبّت في CSS.
  بذلك مقياسه 1:1 في المحورين ولا يكبر مع اتساع النافذة أو تصغير تكبير المتصفّح.
- إعادة الرسم عبر `ResizeObserver` محروسة بتغيّر المقاس، **متزامنة** لا داخل
  `requestAnimationFrame`.
- عرض العمود = نصف الخانة، بحدّ أقصى 24px. الخطوط 2px.
- حدود المحاور أرقام «مضبوطة»: 1 / 2 / 2.5 / 5 / 10 × 10ⁿ — لا `ceil(max)`.
- لا مقياس مزدوج. سلسلتان مختلفتا الحجم = رسمان بمحور سينيّ مشترك.

## 11. التصفية — النمط المعتمد

**معتمد من صاحب المنتج: «مناظير محفوظة + لوحة تصفية».** المرجع الحيّ:
`prototype/admin/filters.html` (النمط ب). أي صفحة فيها جدول تستعمل هذا النمط ولا شيء
سواه.

سبب الاعتماد: شريط التصفية القديم كان يدفع أول صف بيانات إلى **640px** — أي 71% من
شاشة 900px قبل ظهور سجلّ واحد. هذا النمط يخفضه إلى **142px**، ويعترف بأن معظم فتحات
الشاشة تقصد إحدى حالات قليلة معروفة.

### البنية، بهذا الترتيب

```
┌ شريط المناظير ─────────────────────────────────┐  تبويبات بعدّادات
├ سطر الأدوات ───────────────────────────────────┤  بحث + زر «تصفية (n)»
├ لوحة التصفية (مطويّة افتراضيًا) ────────────────┤  hidden حتى تُفتح
├ شريط الإجراءات السياقي (عند التحديد فقط) ───────┤  hidden بلا تحديد
└ الجدول ────────────────────────────────────────┘
```

### قواعد ملزمة

1. **المناظير تبويبات لا أزرار.** `role="tablist"` وداخلها `role="tab"` مع
   `aria-selected`. المنظور النشط بحدّ سفلي `2px` بلون `--accent`.
2. **كل منظور يحمل عدّاده**، محسوبًا من البيانات لا مكتوبًا يدويًا. العدّاد
   `direction:ltr; unicode-bidi:isolate` وأرقامه جدولية.
3. **لوحة التصفية مطويّة افتراضيًا** (`hidden`)، وتُفتح بزرّ يحمل عدد المرشّحات
   الفعّالة كشارة. اختيار منظور يُعيد ضبط اللوحة.
4. **شريط الإجراءات الجماعية لا يُرسم إطلاقًا بلا تحديد.** `hidden` وليس `disabled`.
   نصّه: «حُدِّد n من m» ثم الإجراءات، والهدّامة منها بلون `--wanted`.
5. **لا يُطبع مسار API ولا query string في الواجهة.** مكانه سطر «مصادر البيانات».
6. أي قائمة منسدلة تفتح بضغطة يجب أن توقف انتشار الحدث (`e.stopPropagation()`)،
   وإلا وصلت الضغطة نفسها إلى مستمع الإغلاق العام فأغلقتها في اللحظة التي فُتحت فيها.
7. **حالة فارغة تفرّق بين السببين**: «لا توجد نتائج مطابقة» عند وجود تصفية، وليس
   «لا يوجد شيء» — النفيان مختلفان والثاني كذب.
8. لا `<input type="date">` أصلي في شريط التصفية: يعرض أرقامًا هندية وترتيب
   شهر/يوم بحسب لغة المتصفّح، ما يخالف §4.

### المناظير الفعلية لكل صفحة

القيم أدناه مأخوذة من عناصر التصفية الحقيقية في كل صفحة — لا تخترع غيرها.

**التبويبات بُعد واحد لا أكثر.** التبويب يعني «اختر واحدًا من هؤلاء»، فخلط بُعدين فيه
— حالة المستخدم مع حالة الاشتراك مثلًا — يجعل الاختيارات غير حصرية ويربك القارئ.
البُعد الواحد يكون تبويبات، وبقيّة الأبعاد تنزل إلى لوحة التصفية.

| الصفحة | البُعد | المناظير |
|---|---|---|
| المستخدمون | `fStatus` | الكل · مفعّل `active` · موقوف `disabled` · منتهي `expired` · الأرشيف *(مسار مستقل)* |
| المشرفون | الدور | الكل · مديرون `admin` · مشرفون `mod` |
| الإصدارات | حكم السياسة | الكل · مسموح `allowed` · محظور `blocked` |
| قائمة المطلوبين | الجهة الطالبة | الكل · أعلى الجهات *(إن توفّرت التجميعة)* |

في صفحة المستخدمين يبقى البُعدان الآخران داخل لوحة التصفية المطويّة:
`fSub` (كل الاشتراكات / ساري / معلّق / منتهي / بدون اشتراك) و
`fActive` (الكل / نشط اليوم / غير نشط اليوم).

انتبه: `expired` في `fStatus` تعني حالة المستخدم، و`expired` في `fSub` تعني انتهاء
الاشتراك. قيمتان مختلفتان بالاسم نفسه — لا تخلط بينهما.

## 12. الملف

صفحة واحدة = ملف HTML واحد قائم بذاته. بلا مكتبات وبلا خطوة بناء. الخط الوحيد
المحمَّل من الخارج هو IBM Plex Sans Arabic من Google Fonts. الرسوم SVG مكتوبة يدويًا.

```html
<html lang="ar" dir="rtl" data-depth="all">
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
```

قبل التسليم تحقّق: صفر `position:fixed` · صفر `backdrop-filter` · صفر حركة على
`.pane` · صفر تمرير أفقي عند 390 و 1440 و 1920 · صفر عنصر مقطوع خارج الشاشة.
