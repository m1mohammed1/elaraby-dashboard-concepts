# عشرة تصاميم للنظرة العامة

عشر لوحات إدارية لشاشة «النظرة العامة» في نظام العربي لفحص اللوحات — نفس البيانات
ونفس المادة، وعشر أفكار مختلفة تمامًا في ترتيب الشاشة نفسها.

**كل البيانات في هذه الصفحات توضيحية وليست بيانات حقيقية.** لا توجد هنا أرقام لوحات
حقيقية ولا بلاغات ولا أسماء أشخاص من النظام الفعلي.

## التصاميم

| # | التصميم | الفكرة المنظِّمة |
|---|---------|------------------|
| 01 | الرادار | قرص دائري: الزاوية ساعة، والحلقة بوابة، والنقطة عملية مسح |
| 02 | الشبكة الزمنية | مصفوفة 264 خلية — 11 بوابة × 24 ساعة |
| 03 | النهر | مخطط تدفّق سانكي، ومعه مخطط منفصل لمسار المطلوب |
| 04 | الفرز | بلاغ واحد بحجم كامل وطابور خلفه |
| 05 | الجدار | خريطة مساحات: مساحة كل بوابة تساوي حجمها |
| 06 | العمود الفقري | سجل زمني رأسي تتفرّع منه الأحداث |
| 07 | غرفة التحكم | رقم واحد بحجم 200 بكسل يحتل ربع الشاشة |
| 08 | المدار | حلقات متحدة المركز، والتنقّل بالغوص داخلها |
| 09 | الطبقات | ثلاث طبقات عمق يتحكم بها زر «العمق» |
| 10 | الصحيفة | تقرير بأعمدة يُعاد كتابته عند الضغط على اسم بوابة |

## الاستخدام

- **[index.html](index.html)** — المعرض: العشرة حيّة جنبًا إلى جنب، اضغط أيًّا منها ليفتح كاملًا.
- **[all-in-one.html](all-in-one.html)** — نفس المعرض في ملف واحد مستقل يعمل بلا إنترنت.
- كل تصميم ملف واحد قائم بذاته: HTML و CSS و JavaScript، بلا مكتبات وبلا خطوة بناء.
- **[SPEC.md](SPEC.md)** — العقد المشترك الذي بُنيت عليه العشرة: المادة والألوان والخطوط
  وقواعد الحركة والبيانات وقواعد RTL وحد الإتقان.

الخط الوحيد المُحمَّل من الخارج هو IBM Plex Sans Arabic من Google Fonts.

## ملاحظات

- الشاشات مصمّمة للعرض على 1440×900 وتتدرّج حتى 390 بكسل.
- الحركة ثلاثة أنواع فقط: دخول الصفحة، والأرقام والرسوم، والتفاعل — ولا حركة خلفية مستمرة.
- `prefers-reduced-motion` مُحترَم في العشرة.
- أحمر = مطلوب، وأخضر = سليم، في كل التصاميم.
